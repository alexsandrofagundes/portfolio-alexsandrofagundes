# Portfólio — Alex Sandro Fagundes

Portfólio profissional de Alex Sandro Fagundes, Analista de Engenharia de Software Pleno, com experiência em C#, .NET, Node.js, TypeScript, APIs REST, BFF e sistemas corporativos.

O conteúdo reúne uma trajetória profissional iniciada em 1994, com atuação em mercado financeiro e de capitais, saúde e seguros, ERP, recursos humanos e soluções fiscais. A seção de projetos destaca repositórios públicos de estudo e código aberto; sistemas corporativos são apresentados como experiência profissional, sem expor código proprietário.

## Seções

| Rota        | Conteúdo                                           |
| ----------- | -------------------------------------------------- |
| `/`         | Apresentação, competências e experiências recentes |
| `/projetos` | Projetos públicos hospedados no GitHub             |
| `/stack`    | Tecnologias, ferramentas e domínios de negócio     |

## Tecnologias do site

- Next.js 16, React e TypeScript
- Tailwind CSS
- Testes unitários com Vitest e testes E2E com Playwright
- Acessibilidade validada com axe, metadados Open Graph e dados estruturados
- Cabeçalhos de segurança, sitemap e robots.txt

## Rodando localmente

Pré-requisito: Node.js 22.

```bash
npm ci
npm run dev
```

Validação local:

```bash
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
```

## Publicação

O projeto pode ser publicado na Vercel. Configure `SITE_URL` com a origem HTTPS pública para definir URLs canônicas e sitemap. Em previews e ambientes sem endereço público, o site bloqueia a indexação.
